# Eval datasets (Phase 5)

Labelled synthetic Azure estates: generated estates with ground-truth annotations of
which resources are wasteful, what kind of waste each is, and what the correct
remediation and savings figure would be.

Generated by extending `costsentinel.providers.mock` to vary topology by seed
(ARCHITECTURE.md D25) — the mock provider doubles as the dataset generator, so an
eval exercises the same code path a real run does.

Each dataset ships as:

- `estate.json` — the provider snapshot
- `labels.json` — ground truth: expected signals, their kinds, the expected action
  class for each, and the expected savings within tolerance

See ROADMAP.md Phase 5.
